# examples

| 脚本 | 用途 | 命令 |
|---|---|---|
| `run_demo.py` | 端到端 DBOW 示例（需求→创意→P 评估→汇总→工作流），零配置离线 | `python3 examples/run_demo.py` |
| `run_pdemo.py` | P 体系演示，重点看 **P6 拆为 P6-R1 / P6-R2** | `python3 examples/run_pdemo.py` |
| `run_review.py` | 生成**自包含评审页 HTML**（可勾选/定优先级/导出决策单） | `python3 examples/run_review.py` |

三者都不需要联网、不需要 API Key、不装第三方依赖。
